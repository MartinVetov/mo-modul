# Миграции

Всяка промяна по вече работеща база отива тук като отделен файл:

    ГГГГ-ММ-ДД-кратко-описание.sql

Пример за съдържание:

    -- 2026-09-15, Иван Петров: добавя поле за срок на мярката
    ALTER TABLE entries ADD COLUMN measure_deadline DATE NULL AFTER measure;

Правила:
- файловете се изпълняват по дата, отгоре надолу, и НЕ се променят след сливане;
- всяка миграция трябва да може да се пусне върху реалната база без загуба на данни;
- преди пускане на реалния сървър: `mysqldump -u root mo_analizi > backup.sql`.
